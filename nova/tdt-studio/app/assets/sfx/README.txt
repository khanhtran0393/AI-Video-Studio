THAY THẾ / THÊM SFX MỚI
═══════════════════════════════════════════════════════════

CÁCH 1 — Trong app (đơn giản):
  Right-click vào track SFX → "Chọn file khác..." → pick MP3 từ máy bạn.

CÁCH 2 — Bổ sung vào library (tự động xuất hiện trong menu):
  Copy MP3 mới vào thư mục này. Tên file = tên hiển thị trong menu.
  App tự scan mỗi khi load video.
